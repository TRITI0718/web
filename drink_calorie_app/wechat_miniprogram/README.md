# DRINK CALORIE 微信小程序

这是网页版本的原生微信小程序实现，饮品数据随包发布，不依赖外部接口，也不收集用户信息。

## 本地预览

1. 安装并登录微信开发者工具。
2. 选择“导入项目”，目录指向本文件夹 `wechat_miniprogram`。
3. 测试时可以使用当前的 `touristappid`；真机调试和上传前必须替换为你自己的小程序 AppID。
4. 点击“编译”，检查搜索、品牌、类别、来源、热量区间、排序和加载更多。

## 正式上架前

1. 在微信公众平台注册并完成小程序主体认证。
2. 把 `project.config.json` 中的 `appid` 替换为真实 AppID。
3. 在公众平台填写名称、简介、服务类目、图标和隐私保护说明。
4. 在开发者工具中点击“上传”，填写版本号和项目备注。
5. 在公众平台“版本管理”中提交审核，审核通过后发布。

当前版本只展示本地营养数据，不登录、不定位、不读取通讯录，也不收集用户信息。如果后续增加收藏同步、用户账号、云数据库或网络接口，需要同步更新隐私保护指引和服务器域名配置。
